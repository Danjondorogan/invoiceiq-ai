# InvoiceIQ

AI-Powered Invoice Verification & Fraud Detection Platform

## Features

- Multi-format invoice upload
- OCR-based invoice extraction
- Duplicate invoice detection
- Fraud risk scoring
- Business rule validation
- Dashboard visualization
- AI anomaly detection

## Tech Stack

Frontend:
- React
- TypeScript
- Tailwind CSS

Backend:
- FastAPI
- Python

Database:
- SQLite
- PostgreSQL

AI/ML:
- OCR
- Isolation Forest
